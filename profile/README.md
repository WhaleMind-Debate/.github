# 鲸思云辩 WhaleMind Debate

鲸思云辩，一个学校辩论赛组织，旗下产品为辩论赛提供更现代的解决方案。

## 关于我们

我们是一群热爱辩论的学校辩手，也是辩论赛的组织者。办赛过程中，计时、打分、公示这些环节琐碎又容易出错，我们决定自己动手，把这些事做得更清楚、更体面。

## 旗下产品

**WhaleMind-Hub** —— 辩论赛现场三端协同系统：

- **主席控制台**：指挥赛程、控制计时、公布比分
- **评委打分端**：手机/平板触控打分
- **大屏展示端**：实时呈现倒计时与正反方对比

三端实时同步，让一场比赛从开赛到公布结果都在系统里完成。
